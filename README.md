# Nick's ai — Enterprise AI Project Health & Management Platform

A high-performance, enterprise project management & predictive AI risk platform built with **Node.js (Express)**, **Python Analytics Microservice**, and **Modular ES6 JavaScript/CSS**.

## 🚀 Quick Start in VS Code

### 1. Open in VS Code
Open VS Code and select **File -> Open Folder...** and choose this folder ().

Alternatively, from your terminal:
```bash
cd ~/Downloads/nicks_ai_project
code .
```

---

### 2. Run the Application

#### Option A: Node.js Express Server (Recommended)
1. Install dependencies (if needed):
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Open your browser to **[http://localhost:3000](http://localhost:3000)**.

#### Option B: Python Analytics Microservice
Run Monte Carlo risk simulations independently:
```bash
python3 analytics/risk_engine.py
```
